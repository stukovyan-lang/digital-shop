# ТЗ: сайт магазина цифровых товаров (v1, «игровой неон»)

Макет для согласования: https://claude.ai/artifact/BRnCgfbjMZahuW7nsRrBkk
Референс стилей и анимаций: `neon-theme.css` (лежит рядом с этим файлом). Переносим токены и эффекты из него, а не верстаем заново «на глаз».

## 1. Что делаем

Премиальный и визуально «дорогой» сайт-витрина цифровых товаров для покупателей из Беларуси. Язык — русский.
Первый этап (к субботе): весь интерфейс с моками данных, оплаты и выдачи. Второй этап: подключаем API выдачи заказов (делает Иван) и платёжку.

Приоритеты по порядку: 1) вау-эффект и плавность, 2) скорость загрузки и работа на слабых телефонах, 3) чистая архитектура, чтобы потом легко подключить API.
Десктоп и мобильная версия одинаково важны.

## 2. Стек

- **Next.js** (App Router) + **TypeScript** (strict)
- **Tailwind CSS**: токены из раздела 4 — в CSS-переменных и в теме Tailwind
- **Framer Motion** (`motion`): переходы между страницами, shared layout, микроанимации
- **React Three Fiber** + **@react-three/drei** + **@react-three/postprocessing**: 3D-сцена первого экрана
- **GSAP + ScrollTrigger**: сложные сцены при скролле; **Lenis**: плавный скролл
- **Zustand**: корзина и UI-состояние, сохраняется в localStorage
- **next/font**: Unbounded (заголовки, кириллица), Inter (текст)
- Линтер и форматирование: ESLint + Prettier. Деплой: Vercel (по умолчанию)

Версии — актуальные стабильные на момент установки.

## 4. Дизайн-токены

```
bg #07060D · bg2 #0D0B18 · surface rgba(255,255,255,.045) · line rgba(255,255,255,.10)
text #F4F2FF · muted #A8A3C2
pink (неон, декор) #FF2E88 · pink-text #FF5CA3 · blue (неон) #3B82F6 · blue-text #7AA7FF · violet-accent #A855F7
gradient кнопок: 100deg #E0106F → #2563EB  (белый текст проходит 4.5:1 — светлее не делать)
радиусы: 12 / 14 / 18 / 24 / 28 · стекло: blur 18px + saturate 140%
шрифты: Unbounded 500/700/800 (display, letter-spacing -0.02em), Inter 400–700
```

Фон страницы — два мягких радиальных свечения, розовое и синее, на почти чёрном. Розовый и синий в чистом виде — только для свечения и декора. Для текста — `pink-text` и `blue-text`.

## 5. Анимации (обязательный список)

Общие правила: easing `cubic-bezier(.2,.8,.2,1)`; длительность микроанимаций 200–350 мс, появлений 600–900 мс; анимируем только `transform`, `opacity` и `filter`.

1. **Прелоадер** (только при первом заходе в сессию): градиентный знак с поворотом и пульсом, полоса загрузки примерно на 1,7 с, затем растворение и масштаб 1.04. Не дольше 2,2 с; не показывать, если всё уже в кэше.
2. **3D-hero (R3F)**: 6 стеклянных карточек сервисов парят в пространстве (drei `Float`). Материал `MeshPhysicalMaterial`: transmission, roughness ~0.15, переливающийся отблеск. На карточках логотипы и названия. Сцена наклоняется за курсором, на мобильном — за гироскопом с плавной интерполяцией. Позади — пол из неоновой synthwave-сетки (шейдер с бегущими линиями), звёзды (drei `Stars`), Bloom из postprocessing. Клик по карточке ведёт на товар.
3. **Бегущая строка** сервисов, на hover — пауза.
4. **Появление при скролле**: блоки въезжают снизу на 60 px с blur 6 → 0 и scale .97 → 1. Карточки каталога — каскадом (stagger 60 мс).
5. **Живые карточки товаров**: на hover — подъём на −10 px, наклон rotateX 5°, 3D-tilt за курсором (±8°), вращающаяся конусная неоновая рамка, свечение сверху. На тач-устройствах — лёгкий scale при нажатии.
6. **Переходы между страницами**: `AnimatePresence` + shared layout — карточка товара морфится в hero товара (`layoutId`: логотип, название). Остальные страницы — fade + translateY 28 px + blur.
7. **Фильтр каталога**: активный чип переезжает (`layoutId` подложки), карточки перестраиваются через `layout`.
8. **Корзина**: при добавлении — «полёт» иконки товара в корзину, bump счётчика, кнопка превращается в «Добавлено ✓».
9. **Статус заказа**: прогресс-бар со свечением, точки шагов (готово — градиент, текущий шаг — пульсирующее кольцо и спиннер), в финале — конфетти-вспышка частиц в цветах палитры.
10. **Текст**: градиентный shimmer у акцентных слов, плавные счётчики цифр (count-up при появлении).
11. **Кнопки**: градиент смещается на hover, подъём на 2 px, свечение; на active — scale .98. Фокус — видимое кольцо `0 0 0 4px rgba(59,130,246,.22)`.

## 6. Производительность и автоупрощение

- 3D-сцену грузим лениво: `dynamic(..., { ssr: false })`. Заголовок и CTA первого экрана — обычный HTML вне canvas, это LCP.
- Пока сцена грузится и на слабых устройствах — **CSS-фолбэк**: 3D-карточки на CSS transform, как в макете (`.nx-fcard`, `.nx-grid`).
- Уровни качества: `high` (bloom, transmission, DPR до 1.75) → `medium` (без transmission, DPR 1.25) → `low` (CSS-фолбэк). Выбор — по `navigator.hardwareConcurrency`, `deviceMemory` и drei `PerformanceMonitor` (падение FPS — понижаем уровень).
- `prefers-reduced-motion`: без прелоадера, без 3D и параллакса, только opacity-переходы.
- Canvas ставим на паузу (`frameloop="demand"`), когда hero вне экрана или вкладка скрыта.
- Цели (Lighthouse, мобильный): Performance ≥ 85, LCP < 2,5 с, CLS < 0,05; JS первого экрана без 3D — ≤ 200 КБ gzip.

## 7. Данные и интеграции (на первом этапе — моки)

Каталог — типизированный конфиг `src/data/products.ts`:

```ts
type Delivery = 'auto' | 'manual' | 'pending';
type Product = {
  slug: string; name: string; category: 'telegram' | 'games' | 'ai' | 'music';
  delivery: Delivery; logo: string; description: string;
  recipientFields: Array<'steamLogin' | 'tgUsername' | 'email'>;
  options?: { id: string; label: string; price: number | null }[]; // тарифы, сроки, суммы
  priceFrom: number | null; // null → «[ЦЕНА]»
};
```

Товары v1: Telegram Stars, Telegram Premium, пополнение Steam, смена региона Steam (KZ, UA; `pending`), ChatGPT Plus / Go, Google AI Plus / Gemini (6 мес.), Spotify, PS Plus Турция (`manual`), Xbox (`manual`).

Интерфейсы-адаптеры (`src/lib/api/`), сейчас — мок-реализации:

- `OrdersApi`: `quote(productSlug, optionId, amount)`, `createOrder(cart, contact)`, `getOrder(id)` — статус для опроса раз в 3 с: `created | paid | delivering | done | failed`
- `PaymentProvider`: `createPayment(orderId, method: 'crypto' | 'balance')` → URL редиректа. Провайдер не выбран.
- `AuthProvider`: Telegram Login Widget; проверка подписи — только на сервере (route handler). Пока — мок-пользователь.

Мок `getOrder` проходит по статусам за ~6 с — для демонстрации анимации.
Товары `manual`: ссылка на чат менеджера `https://t.me/<support>`. Текст заказа копируем в буфер с тостом «Текст скопирован».
Все URL, ники и ключи — в `.env` / `src/config/site.ts`.

## 8. Логотипы сервисов

Официальные логотипы — SVG в `/public/brands/`. Берём с официальных brand/press-страниц сервисов и соблюдаем их гайдлайны: без перекраски, искажений и эффектов поверх самого знака. Свечение — только вокруг плитки. Пока файлов нет — плитка с инициалами (как в макете).

## 9. Плейсхолдеры (не выдумывать)

`[НАЗВАНИЕ]`, `[домен]`, `[ЦЕНА]`, `[СРОК]`, `[КОМИССИЯ]`, `[ШЛЮЗ]`, `[УСЛОВИЯ]`, `[ВАЛЮТЫ / РЕГИОНЫ]`, `@[бот]`, `@[канал]`, `@[поддержка]`, `[N]` в счётчиках. Всё это — константы в одном файле `src/config/placeholders.ts`. Отзывы и счётчики показываем только из реальных данных, до этого — блок-заглушка.

## 10. Доступность и качество

Настоящие `<button>`/`<a>`, `aria-pressed` у переключателей, `aria-expanded` у аккордеона, `aria-live` у статуса заказа. Контраст текста ≥ 4.5:1. Зоны нажатия ≥ 44 px. Работа с клавиатуры. Метаданные и OG-картинка для каждой страницы.

## 11. Этапы и приёмка

**Этап 1 (к субботе)**: все страницы из раздела 3 на моках; анимации 1–11; адаптив 360–1440+; уровни качества 3D и reduced-motion.
Приёмка: прохождение «главная → товар → корзина → оплата (мок) → статус → кабинет» без ошибок в консоли; Lighthouse-цели из раздела 6; на слабом Android сайт плавный (CSS-фолбэк).

**Этап 2**: реальные `OrdersApi`, `PaymentProvider`, `AuthProvider`; цены из API; логотипы; домен.
